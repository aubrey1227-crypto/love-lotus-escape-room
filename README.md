## 🎮 遊戲玩法

首頁先選擇 **遊戲模式**，再選難度與關卡數。

### 🙋 個人挑戰模式（學生自用）

1. **選擇難度**
   - 🌱 **新手探索者**：課文大意、字詞義、象徵配對與基本理解（16 題題庫）
   - 🔥 **高手挑戰者**：層次剖析、寫作架構、修辭深究與比較閱讀（16 題題庫）
2. **選擇關卡數**
   - 🚪 **五關密室**：約 3 分鐘，輕鬆體驗
   - 🏯 **十關迷城**：約 5 分鐘，完整挑戰
3. 進入密室後，每關答題**答對即可獲得一枚密碼碎片**。
4. 集齊全部碎片後輸入姓名，即可領取專屬**完成證書**並解鎖終極密語。

| 關卡數 | 密碼碎片 | 通關密語 |
| :-- | :-- | :-- |
| 五關 | 蓮 花 映 君 子 | **蓮花映君子** |
| 十關 | 愛 蓮 說 ・ 出 淤 泥 而 不 染 | **愛蓮說・出淤泥而不染** |

### 🎓 課堂即時模式（教師投影操作）

專為「老師投影 + 全班同步作答」設計，**教師代全班點選**即可完成全班統計。

| 功能 | 說明 |
| :-- | :-- |
| ⏱️ **限時倒數揭曉** | 設定每題 15 / 30 / 45 秒或不限時。倒數條與剩餘秒數會顯示在題目上方，最後 5 秒轉為紅色警示；時間一到**自動鎖定並揭曉答案** |
| 📊 **每題全班答對率** | 逐題顯示「本題結果」與「全班平均」，讓教師即時掌握班級理解程度 |
| 📋 **課堂錯題報告** | 結束後自動產出報告：總答對率、逐題對錯明細、**錯誤集中處的題目（含題幹、正確答案、完整解析）** |
| 🗒️ **教學建議** | 依答對率自動給出後續教學策略建議（100%／≥60%／<60% 三種情境） |
| 🔠 **大字體老師視角** | 題目、選項與解析字級放大，投影機後排學生看得清楚 |
| 🪑 **免姓名／可選座號** | 不必輸入姓名，可選填座號方便對照座位表 |
| 🖨️ **列印報告** | 一鍵輸出成紙本，作為課堂紀錄或補教依據 |

**建議操作流程**

1. 首頁切到「🎓 課堂即時模式」，挑選難度與關卡數（十關迷城適合 25–40 分鐘的語文課堂）
2. 每題讀完題目後開始倒數，讓學生在時間內思考或舉手
3. 時間到自動揭曉答案 → 教師點擊「🔄 再試一次」可重新出題，或直接按「下一關」
4. 全數完成後填座號（選填）→ 產出題目報告 → 可直接列印

**若某題全班答錯**，按「🔄 再試一次」可重新作答，系統會以最新一次結果覆寫該題紀錄。

### 題庫設計原則

- 每題 4 個選項，正確答案固定置於陣列第 0 項，由引擎在作答前**自動隨機洗牌**。
- **所有錯誤選項的長度都與正確答案相當或更長**，學生無法用字數猜答案。
- 每題附完整解析，答錯時亦會顯示，方便課後複習。

## 🖼️ 更換人物形象

右下角的人物是 **手繪 SVG 插圖**（`assets/img/character.svg`，僅 2 KB，任意尺寸皆清晰），刻意繪製成宋代理學士人形象：儒巾、交領右衽、長鬚，手持蓮花呼應「愛蓮說」主題。

若想換成其他形象（例如真人去背圖或陶淵明）：

- **替換插圖**：直接編輯 `assets/img/character.svg` 的繪製內容即可，viewBox 比例維持 `0 0 200 336` 最合適。
- **改用點陣圖**：把圖片命名為 `character.svg` 放進同一資料夾並重新匯出為 SVG 佔位，或修改 `index.html` 第 758 行的圖片路徑：
  ```html
  <img src="assets/img/character.png" alt="周敦頤" onerror="...">
  ```
  圖片若載入失敗，角色會自動隱藏，不影響遊戲進行。

## 👩‍🏫 課堂運用建議

- **課前預習**：學生用「個人挑戰 × 五關」熟悉文本，約 3 分鐘完成，作為暖身或預習檢核。
- **課堂講解**：教師用「課堂即時 × 十關」，配合限時倒數帶動全班思考，結束後依錯題報告立即補教。
- **分組競賽**：投影全班一起作答，以小組計時，答錯可按「🔄 再試一次」重新挑戰。
- **延伸活動**：個人模式的結業證書可列印作為學習獎勵，證書上會自動蓋有「出淤不染」印章。
- **自由探索**：十關題庫每次從 16 題中隨機抽出，適合重複挑戰、鞏固記憶。
