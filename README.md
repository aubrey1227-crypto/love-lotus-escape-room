## 🎮 遊戲玩法

1. **選擇難度**
   - 🌱 **新手探索者**：課文大意、字詞義、象徵配對與基本理解（16 題題庫）
   - 🔥 **高手挑戰者**：層次剖析、寫作架構、修辭深究與比較閱讀（16 題題庫）
2. **選擇關卡數**
   - 🚪 **五關密室**：約 3 分鐘，輕鬆體驗
   - 🏯 **十關迷城**：約 5 分鐘，完整挑戰
3. 進入密室後，每關答題**答對即可獲得一枚密碼碎片**。
4. 集齊全部碎片後輸入姓名，即可領取專屬**完成證書**並解鎖終極密語。

| 關卡數 | 密碼碎片 | 通關密語 |
| :-- | :-- | :-- |
| 五關 | 蓮 花 映 君 子 | **蓮花映君子** |
| 十關 | 愛 蓮 說 ・ 出 淤 泥 而 不 染 | **愛蓮說・出淤泥而不染** |

### 題庫設計原則

- 每題 4 個選項，正確答案固定置於陣列第 0 項，由引擎在作答前**自動隨機洗牌**。
- **所有錯誤選項的長度都與正確答案相當或更長**，學生無法用字數猜答案。
- 每題附完整解析，答錯時亦會顯示，方便課後複習。

## 🖼️ 更換人物頭像

將去背的 PNG 圖片覆蓋到 `assets/img/character.png` 即可（建議直向、人物全身，檔案建議小於 1 MB）。

## 🔊 音效

頁面右上角有 🔊 / 🔇 按鈕可切換音效。

## 👩‍🏫 課堂運用建議

- **課前預習**：以「新手探索者 × 五關」讓學生先熟悉文本，約 3 分鐘即可完成，作為暖身或預習檢核。
- **課堂檢測**：以「高手挑戰者 × 十關」進行完整挑戰，約 5 分鐘，適合作為課堂即時評量或段考前複習。
- **分組競賽**：投影全班一起作答，以小組計時，答錯可按「🔄 再試一次」重新挑戰。
- **延伸活動**：結業證書可列印作為學習獎勵，證書上會自動蓋有「出淤不染」印章。
- **自由探索**：十關題庫每次從 16 題中隨機抽出，適合重複挑戰、鞏固記憶。
